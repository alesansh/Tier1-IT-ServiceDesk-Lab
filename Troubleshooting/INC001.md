
# INC001 – Outlook Synchronization Issue

## 1. Incident Information

- Ticket ID: INC001
- User: John Smith (Fictional)
- Department: Finance
- Category: Software
- Priority: P3 - Medium
- Status: In Progress
- Assigned Technician: Tier 1 Support

## 2. Problem Description

The employee reports that Microsoft Outlook
is not synchronizing incoming or outgoing emails.

## 3. Initial Questions

1. When did the issue start?
2. Is the employee connected to the internet?
3. Does Outlook display an error message?
4. Can the employee access Outlook Web?
5. Are other employees experiencing the same issue?

## 4. Possible Causes

- Internet connectivity problems.
- Outlook Offline Mode enabled.
- Authentication problems.
- Microsoft 365 service disruption.
- Outlook application configuration issues.


## 5. Troubleshooting Performed

The following network diagnostic tests were
performed using macOS Terminal.

### Test 1 - IP Connectivity

Command: ping -c 4 1.1.1.1

Result:
- 4 packets transmitted.
- 4 packets received.
- 0% packet loss.
- Average latency: 50.597 ms.

Finding: IP connectivity to the test destination
was successful.

### Test 2 - DNS Resolution

Command: nslookup outlook.office.com

Result:
- DNS server: 172.20.10.1
- Domain successfully resolved.
- Multiple IP addresses returned.

Finding: DNS resolution was successful.

### Test 3 - HTTPS Connectivity

Command: curl -I --max-time 10 https://outlook.office.com

Result:
- HTTP/2 301 response.
- Server redirected the request to Outlook Mail.

Finding: HTTPS connectivity to the Outlook
endpoint was established.

## 6. Findings

The three network tests completed successfully.

No general IP connectivity, DNS resolution,
or HTTPS connection failure was identified
on the MacBook during testing.

Important limitation:
These tests were performed on macOS and do not
confirm the condition of the employee's Windows
device, Outlook application, account or mailbox.

Further investigation is required.

## Final Investigation Summary

### Investigation Results

The following connectivity tests were successfully performed from a macOS environment:

- **IP Connectivity:** Ping to 1.1.1.1 completed successfully with 0% packet loss.
- **DNS Resolution:** outlook.office.com resolved successfully using nslookup.
- **HTTPS Connectivity:** A request to outlook.office.com returned HTTP 301, indicating a successful connection and redirection.

### Outstanding Checks

The following checks could not be completed:

### Conclusion

The network connectivity tests were successful from the lab environment. However, these results do not confirm that the affected user's Outlook application, device, account, or mailbox is functioning correctly.

The root cause remains unidentified.
