# INC004 – Unable to Access Websites

## Incident Information

- **User:** Sarah Wilson
- **Department:** Finance
- **Issue:** Unable to access certain websites
- **Category:** Network / Connectivity
- **Priority:** P2 – High
- **Status:** Resolved (Simulated Scenario)

## Problem Description

Sarah reported that some websites were not loading on her computer. The browser displayed an ERR_CONNECTION_TIMED_OUT message.

Other applications, including Outlook and Microsoft Teams, were working normally.

## Troubleshooting Performed

All results below were simulated for this learning project.

1. Confirmed that only certain websites were affected.
2. Checked Outlook and Microsoft Teams. Both were working normally.
3. Identified the browser timeout error.
4. Tested the affected website from another computer on the same network. It worked.
5. Tested the website using another browser on Sarah's computer. It worked.
6. Tested Chrome Incognito Mode. The website worked.
7. Reviewed Chrome extensions and identified a recently installed extension.
8. Temporarily disabled the extension and tested the website again. It worked.
9. Closed and reopened Chrome. Sarah confirmed that all websites were working normally.

## Findings

The problem was isolated to Sarah's normal Chrome profile.

The affected website worked in another browser and in Incognito Mode. After disabling the recently installed extension, normal browsing was restored.

## Root Cause

A recently installed Chrome extension was interfering with access to certain websites.

## Resolution

The problematic extension was temporarily disabled. Sarah confirmed that the affected websites were accessible after restarting Chrome.

No DNS, firewall, or network configuration changes were required.

## Final Status

Resolved – User confirmed successful access.

## Notes

This is a fictional IT support scenario created for learning purposes. All troubleshooting results and user confirmations were simulated. No actual company systems or devices were modified.
