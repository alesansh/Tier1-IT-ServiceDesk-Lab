# INC005 – Unable to Access Shared Folder

## Incident Information

- **User:** James Taylor
- **Department:** Legal
- **Issue:** Unable to access shared folder
- **Category:** Access / Permissions
- **Priority:** P3 – Medium
- **Status:** Resolved (Simulated Scenario)

## Problem Description

James reported that he could not access the Legal shared folder. Windows displayed a "Network Path Not Found" error.

The affected network path was:

`\\FILESERVER01\Legal`

## Troubleshooting Performed

All results below were simulated for this learning project.

1. Confirmed that James was using the correct UNC path.
2. Tested connectivity to FILESERVER01 using ping. The test was successful.
3. Tested SMB connectivity using Test-NetConnection on port 445. The connection was successful.
4. Confirmed that other Legal employees could access the folder.
5. Confirmed that James could access other shared folders.
6. Reviewed James's Active Directory group membership.
7. Found that James was not a member of the Legal-Shared-Folder security group.
8. Requested manager approval for the access change.
9. The manager approved the request.
10. An authorized administrator successfully added James to the security group.
11. James signed out and signed back into Windows.
12. Tested the shared folder again. James confirmed that access was working.

## Findings

The network connection and SMB service were working correctly.

The problem was isolated to James's access permissions for the Legal shared folder.

## Root Cause

James was missing membership in the Legal-Shared-Folder security group.

## Resolution

After manager approval, an authorized administrator added James to the correct Active Directory security group.
