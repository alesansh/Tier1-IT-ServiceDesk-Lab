# INC002 — Account Locked

## Incident Information

- **Incident ID:** INC002
- **User:** Mary Johnson
- **Department:** HR
- **Issue:** User account locked
- **Priority:** P2 — High
- **Status:** Resolved (Simulated Scenario)
- **Category:** Account and Access Management

## Incident Description

Mary Johnson reported that she could not sign in to her work account because the system displayed an incorrect username or password message.

## Initial Investigation

The following information was collected during the simulated investigation:

- The user reported an incorrect username or password error.
- Mary confirmed that she had not recently changed her password.
- Active Directory showed that the account was locked.
- Simulated security log findings indicated repeated authentication attempts using old credentials.
- Mary confirmed that she still needed to use her old laptop.
- Outlook was identified as the application configured with outdated credentials.

## Troubleshooting Performed

The following troubleshooting activities were simulated for learning purposes:

1. Collected information about the login error.
2. Investigated the account lockout status in Active Directory.
3. Reviewed simulated security event log findings.
4. Identified the old laptop as a possible source of repeated authentication attempts.
5. Identified Outlook as the application using outdated credentials.

## Root Cause

Outdated Outlook credentials on the old laptop were identified as the probable cause of repeated authentication failures and the account lockout.

## Corrective Actions

The following corrective actions were simulated:

1. Updated the outdated Outlook credentials.
2. Unlocked Mary's account in Active Directory.
3. Asked the user to test Outlook access.
4. Monitored the account for recurring lockouts.

## Final Verification

All simulated verification checks were successful:

- Outlook credentials: Updated.
- Account status: Successfully unlocked.
- Outlook access: Working correctly.
- Recurring account lockout: No further lockouts observed.

## Final Resolution

**Status:** Resolved (Simulated Scenario)

**Resolution Summary:** The outdated Outlook credentials were updated and the account was unlocked. Mary successfully regained access to Outlook, and no further account lockouts were observed during the simulated verification.
