# Tier 1 IT Service Desk Lab\
\
## Project Overview\
\
This personal project simulates the daily\
activities of a Tier 1 IT Support Technician\
in a corporate environment.\
\
The objective is to practice incident management,\
technical troubleshooting and IT documentation.\
\
## Project Objectives\
\
- Create and manage support tickets.\
- Identify incident priorities.\
- Troubleshoot common technical issues.\
- Document technical investigations.\
- Practice incident resolution and escalation.\
\
## Tools and Technologies\
\
- macOS Terminal\
- GitHub\
- TextEdit\
- CSV\
- Markdown\
- Networking fundamentals\
- Active Directory concepts\
\
## Incident Scenarios\
\
1. Microsoft Outlook synchronization issue.\
2. User account lockout.\
3. Printer connectivity problem.\
4. DNS and network connectivity issue.\
5. Shared folder access problem.\
\
## Project Scope\
\
This is an independent learning project.\
\
All employee names and incident scenarios are fictional.\
Scenarios are simulated unless otherwise identified\
as hands-on tests.\
\
## Learning Outcomes\
\
- Incident management\
- Troubleshooting methodology\
- Technical documentation\
- Problem-solving\
- IT Service Desk fundamentals\
}
